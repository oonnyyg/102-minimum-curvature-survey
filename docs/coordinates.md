# 坐标与角度约定

## 坐标系

- 局部平面坐标：`east`（东）、`north`（北），单位米。
- `elevation` 为孔口高程（向上为正），单位米。
- 每站方向用单位向量 `u = (east, north, down)` 表示，向下为正。

## 角度约定

- 倾角 `inclination`：自竖直向下方向量取，范围 `[0, 180]` 度。
  - `0` = 竖直向下，`90` = 水平，`180` = 竖直向上。
- 方位角 `azimuth`：自北顺时针量取，范围 `[0, 360)` 度。
- 方向向量：`u = (sin(i)·sin(a), sin(i)·cos(a), cos(i))`，
  其中 `i`、`a` 为弧度。

## 最小曲率法

- 相邻向量夹角 `β = acos(clamp(u1·u2, -1, 1))`，取 `[0, π]`。
- 当 `β ≥ π − 1e-8` 弧度时整批拒绝。
- 比例因子 `RF = 2·tan(β/2)/β`；`β = 0` 时取 1；
  `β < 1e-6` 时用级数 `1 + β²/12 + β⁴/120` 稳定计算。
- 段位移：`Δ = Δmd · RF/2 · (u1 + u2)`，逐段累计东、北、向下位移。
- 高程 = 孔口高程 − 累计向下位移；垂深 TVD = 累计向下位移。

## 狗腿度与闭合方位

- 段夹角（狗腿角）以度报告；狗腿度 = 段夹角度数 × 30 / 段测深差（度/30米）。
- 水平偏移 = `hypot(累计东, 累计北)`；≤ 1e-9 米时闭合方位为 `null`，
  否则为 `atan2(东, 北)` 归一至 `[0, 360)` 度。

## 输入格式

```json
{
  "holes": [
    {
      "id": "H1",
      "collar": {"east": 0.0, "north": 0.0, "elevation": 100.0},
      "stations": [
        {"md": 0, "inclination": 0, "azimuth": 0},
        {"md": 50, "inclination": 10, "azimuth": 90}
      ]
    }
  ]
}
```

- 孔号 `id` 全局唯一；每孔至少两个测站。
- 测深 `md` 从 0 开始且严格递增，不自动排序。
- 所有数值必须有限；任何非法输入导致整批失败且不生成报告。

## 输出

- `<id>_stations.csv`：逐站测深、东/北坐标、高程、垂深、水平偏移、
  闭合方位、段夹角、狗腿度（首站段指标为空）。
- `<id>.json`：孔底位置（测深、东、北、高程）、全孔最大狗腿度及逐站数据。
